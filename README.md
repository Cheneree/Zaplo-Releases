# Zaplo — downloads

Zaplo is a media player for Android TV, Fire TV, Android phones and tablets. You bring your own playlist: an M3U link or an Xtream Codes login from your own provider. Live TV with a programme guide, movies, series and catch-up, with a remote-friendly layout.

> **Zaplo is a media player only. It does not include, sell or recommend any channels, playlists or providers.**

## Get Zaplo

- **Fire TV / Android TV:** install the free *Downloader* app, enter `zaplo.tv/get` and install.
- **Phone or tablet:** download the latest APK from [Releases](../../releases/latest) or [zaplo.tv/download](https://zaplo.tv/download).

Full instructions: [zaplo.tv/download](https://zaplo.tv/download)

## Set up

1. Open Zaplo. Your **Device ID** is shown at the bottom of the screen.
2. Send your playlist from [zaplo.tv/upload](https://zaplo.tv/upload) using that Device ID, then choose **Accept** on the TV.
3. Watch. A free trial is included; after that you can activate the device at [zaplo.tv/activate](https://zaplo.tv/activate).

## Check your download

Each release lists the APK's SHA-256 and the signing certificate fingerprint. The same details are on [zaplo.tv/download](https://zaplo.tv/download). Only install Zaplo from this page or zaplo.tv.
